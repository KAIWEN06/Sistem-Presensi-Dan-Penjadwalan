# Sistem Presensi dan Penjadwalan SD GMIM 12 Manado

Aplikasi berbasis web untuk mengelola **presensi siswa**, **presensi guru**, **jadwal pelajaran**, dan **laporan sekolah** secara digital di SD GMIM 12 Manado.

## 🚀 Fitur Utama

- Presensi siswa harian
- Presensi guru
- Penjadwalan pelajaran
- Dashboard admin
- Laporan PDF
- Multi role user (Admin, Guru, Orang Tua)
- Responsive design (Desktop, Tablet, Mobile)

## 🛠️ Teknologi

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL / Supabase

### Deployment
- Vercel
- Railway / Render
